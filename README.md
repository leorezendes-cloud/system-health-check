# System Health Check

A beginner Bash script that performs basic system and network diagnostics on macOS.

## What It Checks

- Curent user
- Home directory
- Current working directory
- Disk space
- Memory information
- IPv4 addresses
- Internet connectivity
- DNS resolution
- Default network gateway
- macOS version
- System architecture

## Skills Practiced

- Bash scripting
- macOS Terminal
- Command substitution
- Conditional statements
- Pipes and 'grep'
- Output redirection
- Basic networking
- Git and GitHub

## Usage

Run the script from terminal:

```bash
./health-check.sh
```

To save the results to a report:

```bash
./health-check.sh > health-report.txt ```
